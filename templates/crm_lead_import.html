File Format

Required: a phone column. Everything else is optional.

Columns that can be imported:
{% for f in writable %}{{ f }}{% endfor %}

Other columns in the file are ignored rather than rejected, so a CSV exported from this CRM can be edited and imported straight back.

  • Phone numbers are normalised, so 09847312534 and 919847312534 are treated as the same person.
  • A blank cell means "leave as-is", never "clear this field" — a partly-filled spreadsheet cannot wipe data the CRM already holds.
  • Conversation state (stage, chat history, timestamps) cannot be imported: those belong to the WhatsApp bot.
  • Maximum 5,000 rows per file.
  • Save as UTF-8 CSV. Excel's default export works.
